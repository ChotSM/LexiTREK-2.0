## Files

## Separate learner storage
This edition uses different browser storage keys from the current LexiTrek:
- `lexitrekDSKP555Profiles`
- `lexitrekDSKP555ActiveProfileId`

This prevents the new edition from reading or overwriting learner progress in the existing version.

## GitHub Pages
Create a new repository, upload the three files, and keep `index.html` at the repository root.
